Wi-Fi para el sistema instalado

Opcional. Escribe el nombre exacto de tu red y su contraseña. El Live no intentará conectarse ahora: Dex-Installer permanece activo y DexOS intentará conectarse después del primer reinicio.

Si lo dejas vacío, DexOS arrancará con Ethernet/NetworkManager normal y podrás configurar Wi-Fi luego con el comando wifi.

La contraseña se guarda con permisos de root en el sistema destino hasta que NetworkManager cree el perfil en el primer arranque. Nunca se registra en los logs del instalador.

Partición para DexOS

Se lee directamente la tabla GPT/MBR, no sólo los filesystems. Una partición creada en Windows y dejada sin formato aparecerá como “Sin formato” y puede usarse si tiene al menos 1 GiB.

También admite espacio no asignado: si redujiste una partición en Windows y quedó un hueco sin volumen, aparecerá como “Espacio no asignado”. DexOS creará ahí una nueva partición únicamente después de la confirmación final; no necesitas formatearla previamente en Windows.

La ESP contiene los cargadores UEFI de Windows/Linux. DexOS añadirá su carpeta sin borrar ni formatear la ESP. Si el disco permite GRUB BIOS, “Ninguna” instala sólo el cargador BIOS.

Se anunciará por mDNS con .local.
